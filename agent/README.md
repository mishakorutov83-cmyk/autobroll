# Видео-агент: исходники → монтаж по шаблону → варианты

Вы загружаете исходный материал, агент сам монтирует ролик по выбранному шаблону и делает
N разных вариантов с тем же смыслом. Перед рендером вы проверяете план.

```
исходники ──▶ 1. ingest   речь со словами, лица, чёрные кадры, контактные листы, прокси 1080×1920
              2. plan     Claude: шаблон + факты → основной монтаж + N вариантов (JSON) → plans.md
              3. check    Claude: смысл каждого плана сверяется с исходником
              ── вы читаете plans.md, правите словами (--feedback) или руками (plans.json) ──
              4. render   план → Remotion (субтитры, заголовок, подписи, перебивки) → mp4
```

## Команды

```bash
pip install -r scripts/reel/requirements.txt -r agent/requirements.txt   # + bash scripts/reel/setup.sh
export ANTHROPIC_API_KEY=...

python3 -m agent ingest dior "https://drive.google.com/file/d/…/view" --prompt "Dior Maison, Таро"
python3 -m agent plan dior --template stylist_story -n 3
python3 -m agent plan dior --feedback "в v2 убери кусок про возраст, хук короче"
python3 -m agent render dior                 # или --only main,v2 / --stills 30,300
```

Результат: `out/agent_<проект>_<id>_master.mp4` (1080×1920, −14 LUFS) и `_preview.mp4` (≤ 28 МБ).

## Файлы

| Файл | Что делает |
|---|---|
| `plan.py` | Схема монтажного плана — контракт между Claude и рендером |
| `templates/*.yaml` | Шаблоны: стиль + правила драматургии (историю агент строит заново под каждый ролик) |
| `ingest.py` | Анализ исходников, ничего не решает |
| `brain.py` | Запросы к Claude API: план + варианты, проверка смысла, текст для согласования |
| `build.py` | План → `public/agent_<проект>_<id>.props.json` (резка по словам, кадрирование по лицу) |
| `__main__.py` | Консольные команды; Telegram-бот будет вызывать те же функции |

## Что умеет план
- клипы из любых исходников, крупности N/M/C, наезд, punch-in;
- субтитры: вычитанный текст ложится на реальные тайминги слов, 1–2 акцента;
- `hook` — заголовок сверху, `label` — подпись к предмету;
- `inserts` — перебивка под слова: картинка из другого момента поверх звука
  (голос говорит «Звезда» — в кадре тарелка L'Étoile);
- стиль варианта: акцентный цвет, высота субтитров, общий зум.

## Стоимость Claude
Основная часть счёта — то, что модель пишет в ответ (рассуждения и планы), поэтому важны модель и уровень рассуждений.
- **Профили** (`AGENT_PROFILE` в `.env`): `quality` — везде Opus; `balanced` (по умолчанию) — основной монтаж на Opus, варианты и проверка смысла на Sonnet;
  `economy` — основной монтаж на Sonnet, варианты и проверка на Haiku. Каждый шаг можно настроить отдельно (`AGENT_VARIANT_MODEL` и т.д.).
- **Варианты — «рецепты»:** вариант перечисляет, какие клипы основного монтажа взять и в каком порядке, и пишет только новое — ответ в разы короче.
- **Кэш:** расшифровка, кадры и шаблон отправляются один раз, повторные запросы (порции вариантов) читают их за долю цены.
- **Счётчик:** приложение и бот показывают «Claude ≈ $…» по шагам; журнал — `work/agent/<проект>/usage.json`.
- Если дешёвая модель отклонила запрос, шаг повторяется на основной модели.

## Шаблоны
| Шаблон | Для чего |
|---|---|
| `live_showroom` | Живой разговор в камеру в шоуруме/магазине/салоне. Собран по 5 роликам-образцам: холодный старт с середины мысли, детали вещи крупно, личная история, цена в конце; простые белые субтитры, цифры крупнее, без плашек и музыки, окно-врезка (pip) для процессов |
| `stylist_story` | История клиента → товар на перебивках → вывод; заголовок-хук и подписи к предметам |
| `interview_qa` | Интервью «вопрос → ответ → реакция» (стиль серии «Люди нашего места») |

## Приложение для iPhone (`web.py` + `web/`)
Веб-приложение на том же сервере, ставится на экран «Домой» из Safari: вход по коду (`WEB_PASSWORD`),
загрузка видео из «Фото» любого размера частями с докачкой, выбор шаблона и числа вариантов (1–30),
план с проверкой смысла → «Рендер» или правки словами, готовые ролики с плеером, «Сохранить видео» и текстом поста.
Проекты общие с ботом (`projects.py`), тяжёлые задачи идут одной очередью (`jobs.py`), всё запускает `python3 -m agent.app`.
Без Claude для проверки интерфейса: `AGENT_FAKE_BRAIN=1`.

## Файлы на сервере (`inbox.py`)
Видео можно не слать через Telegram: положите их в папку `inbox/` и нажмите в боте «📁 Папка сервера». Готовые ролики лежат
в `out/ready/<дата>_<имя>/` (полное качество + текст поста). Папка источников меняется переменной `AGENT_INBOX`.

## Telegram-бот (`bot.py`)
1. Пришлите видео (лучше файлом) или ссылку на Google Drive — можно несколько, всё попадёт в один проект.
2. Кнопками выберите шаблон и число вариантов → «Монтировать».
3. Бот пришлёт план и проверку смысла → «Рендер» или «Правки» (пишете словами, что поменять).
4. Бот пришлёт все ролики с текстом поста.

Запуск на сервере (VPS вне РФ, 8 ядер / 16 ГБ):
```bash
cp .env.example .env        # BOT_TOKEN, ALLOWED_USERS, TELEGRAM_API_ID/HASH, ANTHROPIC_API_KEY
docker compose up -d --build
```
`docker-compose.yml` поднимает свой Telegram Bot API сервер: облачный API отдаёт боту файлы только до
20 МБ, свой — до 2 ГБ. Локально без Docker: `BOT_TOKEN=… python3 -m agent.bot` (тогда только файлы ≤ 20 МБ
или ссылки на Drive).
