# AutoBroll — заметки для Claude

## Интервью-Reels «Люди нашего места»

Серийный пресет (стиль) зафиксирован по выпуску 1 (Мовсар) в `scripts/reel/preset.py`.
**Фиксирован только стиль, не драматургия.** Для каждого нового интервью заново читать
ВЕСЬ транскрипт и самостоятельно строить лучшую историю; таймкоды/порядок выпуска 1
(`docs/episodes/ep1/edl.py`) — только пример формата.

### Команда пользователя
«Новый выпуск: <ссылка на видео>» (+ по желанию: имя гостя, скорость). Больше ничего не спрашивать —
делать полный цикл и прислать готовый файл.

### Несколько файлов одного интервью (как выпуск 3)
`gdown --folder <url> -O work/epN/raw` → ffprobe (длительность, параметры) → распознать начало и конец
каждого файла, чтобы определить порядок и повтор на стыке → склеить `ffmpeg -f concat -c copy`
(если параметры совпадают; повтор на стыке — обрезать) → `prepare.py work/epN/raw/joined.mp4 epN`.
Историю строить по всему интервью, не по файлам.

### Конвейер (всё уже установлено SessionStart-хуком; вручную: `bash scripts/reel/setup.sh`)
1. `python3 scripts/reel/prepare.py <url|файл> epN` — скачивание, аудио, транскрипт со словами,
   лица. Ничего не апскейлит. Читать `work/epN/transcript.txt`.
2. Написать `work/epN/edl.py` (формат — `docs/episodes/ep1/edl.py`): фрагменты, исправленный текст
   субтитров, акценты, крупности, GUEST, LOWER_THIRD_CLIP, OUTRO.
3. `python3 scripts/reel/build.py epN --check` — режет по границам слов, кодирует ТОЛЬКО выбранные
   фрагменты, собирает props; `--check` дослушивает только помеченные склейки (не весь ролик).
   Поправить edl.py/OVR при необходимости, перезапустить с `--no-media`, если менялся только текст.
3b. `python3 scripts/reel/restore_audio.py epN` — восстановление диалога (стандарт с выпуска 2):
   звук выбранных фрагментов из ОРИГИНАЛА → WPE + DeepFilterNet3 (подавление ≤ 18 дБ) → HPF/EQ/де-эссер/
   компрессия/лимитер, голос ведущего выравнивается по гостю. Агрессивнее не делать — начинает «есть» слова.
   Параметры подбирать под запись (`AUDIO = {dfn_db, wpe_taps, post}` в edl.py, пример — ep4): сравнить 3–5
   вариантов по STOI/SNR (SQUIM) + уверенности Whisper (падение = артефакты) + разбросу фона между
   фрагментами. dynaudnorm в пост-цепочке может «качать» фон между склейками — тогда убрать (ep4: 15 дБ, без него).
   HOST_CLIPS — если реплики ведущего не определяются по плану (split, общий план);
   HOST_SIDE = "R", если ведущий сидит справа в кадре (по умолчанию "L"; ep4).
4. `python3 scripts/reel/render.py epN --stills 60,300,…` — пара кадров для проверки (секунды).
5. `python3 scripts/reel/render.py epN` — один рендер → `out/epN_master.mp4` (1080×1920, −14 LUFS)
   + `out/epN_preview.mp4` (≤ 28 МБ, перекодирование мастера) + `out/epN_sheet.jpg`, `out/epN_first20.jpg`.
   Посмотреть листы, отправить пользователю preview (в чат проходит только ≤ 30 МБ), сообщить путь к мастеру.

### Правила монтажа (пресет)
- 9:16, 1080×1920, H.264/AAC, 2:40–3:00 (после ускорения), без музыки и B-roll.
- Хук — самая сильная реальная реплика гостя (0–5 с) → «как зовут/откуда» + lower-third →
  живой диалог «вопрос ведущего → ответ → реакция». Ведущего не вырезать.
- Скорость речи `SPEED` = 1.10 (пресет; в edl.py или `--speed` 1.0 / 1.10 / 1.15 / 1.20), тон сохраняется.
- Крупности N/M/C = 1.06/1.16/1.28, punch-in внутри длинных клипов, смена ~каждые 5–8 с,
  статичный общий план на двоих → «виртуальные камеры» через SHOTS/FACE_MIN_W в edl.py (пример — ep2),
  длинные проводки камеры и кадры рук/стола вырезать.
- Исходник низкого разрешения: цифровое увеличение ограничено автоматически (preset MAX_MAG*):
  лицо в исходнике < 80 px → растяжение исходника не больше ×3.4 и без сверхкрупных планов; иначе ≤ ×4.0.
  build.py сам обрезает зум и пишет, какие планы ограничены. Качество картинки важнее смены крупности:
  если крупный план упирается в предел, чередовать его с общим, а не растягивать сильнее.
  Предупреждение «same framing across the cut» — поменять план на одной стороне склейки
  (для ручной камеры, где ракурс меняется сам, можно игнорировать).
- Горизонтальный исходник (16:9): полноэкранный вертикальный кроп сам по себе растягивает ×(1920/высота),
  при мелких лицах это выше лимита → `LAYOUT = "split"` в edl.py (гость сверху, ведущий снизу,
  PANELS/PANEL_FACE_Y/HOST_CLIPS, субтитры на стыке CAPTION_TOP_PCT≈49.5, титр LOWER_THIRD_TOP≈36; пример — ep3).
  build.py сам предупреждает, если полный кроп превышает лимит.
- Горизонтальный HD-исходник (1080p) с крупными лицами (≥ 80 px): обычный полноэкранный стиль —
  планы по одному человеку (SHOTS с субъектом "L"/"R"), окно 9:16 сдвигается к человеку (focusX),
  смена субъекта только между клипами (пример — ep4). HD-фрагменты кодируются в родном разрешении.
- Диск: каждый рендер/стоп-кадр копирует public/ в /tmp (render.py/stills.mjs чистят за собой);
  после выпуска удалять рабочие wav в work/epN.
- AI-апскейл (sr_clean.py) — только по согласованию: SPAN дал малый прирост при ~3 с/кадр,
  Real-ESRGAN даёт «пластиковые» лица — не использовать.
- Субтитры clean/Inter, до 2 строк, 1–2 акцентных слова в сильных репликах, текст вычитывать вручную
  (Whisper ошибается в именах, топонимах и коротких репликах ведущего).
- Финал: ресторан/блюдо → end card «ЛЮДИ НАШЕГО МЕСТА / Новые истории людей из Китая» (OUTRO, 3 с).
